# 排課系統
作者：王老師<br>
原始專案：[GitHub](https://github.com/Nov20Firth/JHShoolScheduler/edit/main/README.md)

利用 **python Google OR-Tools** 自動產生國中excel課表。
# 功能與限制
## 硬限制
> ✅同一門課同一天最多一節。<br>
> ✅嚴格檢查每班是否確定是35節(5天各7節)<br>
> ❌無法排第8節<br>
> ❌不連兩天上體育課<br>
> ✅專科教室同時段最多一班使用：<br>
## 軟限制
> 1️⃣考科避免超過單日5節<br>
> 2️⃣考科避免連續兩天都沒課<br>
> 3️⃣老師避免連上第4、5節<br>
> 4️⃣老師避免連續3節課<br>

## 使用方式
測試階段僅接受google表單回傳<br>
1.網頁填表格並下載input.txt，上傳到google表單<br>
2.我會寄送`暫定課表.html`到您信箱，調整完再將`暫定課表.json`檔案回傳給我<br>
3.最終寄送`課表.xlsx`Excel檔案給您。<br>

## 已知限制
- 瀏覽器微調僅能交換同班兩堂未鎖定課程，不能跨班拖曳。
- 綁課不能直接在暫定課表中移動。

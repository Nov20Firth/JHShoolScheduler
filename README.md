# 排課系統
作者：王老師<br>
目前版本：`v0.4.0`<br>
原始專案：[GitHub](https://github.com/Nov20Firth/JuniorHighSchoolScheduler)

利用 **python Google OR-Tools** 自動產生國中excel課表。
# 功能與限制
## 硬限制
✅同日同科最多一堂，若以固定排課排定則不在此限。<br>
(註：若想將某課連堂，請先暫時以固定排課實現)<br>
✅嚴格檢查每班是否確定是35節(5天各7節)<br>
❌無法排第8節<br>
❌不連兩天上體育課<br>
✅專科教室同時段最多一班使用：<br>

## 軟限制(權重)
每日考科超過 5 節：60
教師避免連上第 4、5 節：40
考科避免第 7 節：30
教師避免連續 3 節：20
導師避免連上第 1、2 節：10
考科避免連續兩天沒課：5
考科避免第 5 節：4
教師避免連上第 6、7 節：3

# 使用
測試階段僅開放Google表單回傳方式。
1. 開啟 `index.html`，依序填寫資料(班級、教師、課程、固定課、綁課及教師不可排時段)
2. 按下「檢查並下載 input.txt」
3. 上傳至[Google表單](https://forms.gle/PbWZd8zyxTfZEP276)。

## 已知限制
- 瀏覽器微調僅能交換同班兩堂未鎖定課程，不能跨班拖曳。
- 固定綁課不能移動。
- 不同科互綁的同日兩堂課可對調。

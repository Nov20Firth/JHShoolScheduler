# 更新日誌

## v0.2.2 — 2026-08-03
本次更新調整軟限制優先順序，並完成公開發布前的資料與錯誤處理修正。

### 軟限制調整
- 導師偏好由「課程優先排上午」改為「避免連上第 1、2 節」。
- 將每週至少 3 堂考科的「避免連續兩天沒有課」移至第 6 優先。
- 目前完整權重依序為 100、60、30、20、10、5、3。

### 發布前修正
- 課程需求新增一般表單輸入，提供常用科目、預設堂數與自訂校定課程，並保留快速貼上。
- 綁課逐堂設定簡化為只顯示第幾堂，不顯示普通班科目交錯的內部處理方式。
- 每個「班級＋科目」限制為一筆課程，並拒絕小數堂數。
- 刪除課程或教師時，同步清除相關固定課與整組綁課。
- 求解逾時與硬限制無解改用不同訊息。
- 課表輸出檔正在使用時，改為顯示關閉 Excel 的提示。
- 修正每週至少 3 堂考科的教師若整天不可排，可能被誤判為硬限制無解的問題。

## v0.2.0 — 2026-08-03
本次更新完成新版綁課資料與 Python 求解器整合。

### 綁課
- 新增一般綁課、特教抽離綁課。
- 不同科綁課支援多班、多科。
- 綁課時段可由系統安排。
- 不同科的普通班科目由 Python 依堂數與排課限制自動交錯。

### 資料輸入
- 使用 `BK` 記錄綁定班級與科目堂數，使用 `BT` 記錄每堂時段與特教授課內容。
- 支援匯入新版 `input.txt`，還原教師、課程、綁課與不可排時段。
- 支援匯入`排課.xlsx`，快速讀取教師職稱、排課需求。
- 提供依科目、導師及主任關鍵字快速選取教師。

### 已知限制
- 專科教室及體育場地容量尚未提供設定介面。
- 不支援第 8 節、單雙週、協同教學及教師鐘點計算。
